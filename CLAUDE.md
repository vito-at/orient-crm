# Заметки для Claude

- Код CRM — в `crm/` (Next.js 15, Prisma/Postgres, интерфейс на RU/UZ/EN).
- Отложенные задачи и идеи — в `ROADMAP.md`. Когда владелец спрашивает «что мы хотели сделать?», напомнить по этому файлу. После того как задача сделана, убрать её оттуда; новые отложенные задачи дописывать туда же.
- Интеграция с сайтом Orient Visa (vito-at/orient-visa): визовые заявки приходят с сайта после оплаты, визовики работают в CRM, статусы уходят обратно на сайт. Формат обмена — `docs/orient-visa-integration.md` (та же копия — `docs/crm-integration.md` в репозитории сайта). Перед работой над интеграцией прочитать; изменения вносить в оба репозитория.
- Изменения, которые затрагивают деньги (расчёт зарплаты `crm/src/lib/salary.ts`, прибыль, курсы, финансы, отчёты по деньгам), перед выкладкой перепроверяет отдельный агент (Agent) «на свежую голову»: даёт ему дифф и правила владельца, он ищет ошибки на конкретных примерах (минусы, валюты и курсы, периоды, чужие/свои сделки). Решение владельца 15.11.2026. Для мелких правок (тексты, кнопки) не нужно.
- По расписанию работают автоматические проверки (созданы 15.11.2026): «Проверка CRM раз в 3 дня», «Изменения визовых правил — раз в неделю» (по понедельникам), «Техосмотр CRM — раз в месяц» (2-го числа). Каждая пишет владельцу только если что-то нашла.
